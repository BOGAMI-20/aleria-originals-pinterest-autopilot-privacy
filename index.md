# Privacy Policy — Pinterest Autopilot

**Last updated: November 9, 2026**

## 1. Overview

Pinterest Autopilot is a private, locally operated application used by Aleria Originals to manage, review, schedule, and publish Pinterest Pins for its own Etsy shop.

The application is not a public service. It is designed for use by the shop owner and is not intended for multiple users, public registrations, or managing other people's accounts.

This Privacy Policy explains what information the application accesses, how it is used, where it is stored, and how it can be deleted.

## 2. Information We Access and Process

### Etsy shop information

When an Etsy account is connected, Pinterest Autopilot uses Etsy's official API with read-only permissions to access:

- Shop name, shop ID, shop URL, and associated account information.
- Public listing information, including listing IDs, titles, descriptions, prices, currencies, tags, listing status, and public listing URLs.
- Listing images, including image IDs, image URLs, image dimensions, image order, and available image descriptions.
- Synchronization timestamps and technical synchronization records.

The application uses this information to organize listings, review images, prepare Pin content, and associate Pins with the correct Etsy listing.

**The application does not request or retrieve Etsy customer orders, buyer names, delivery addresses, phone numbers, email addresses, payment information, or transaction records.**

### Pinterest account information

When a Pinterest account is connected, the application uses Pinterest's official API to access:

- Pinterest account username and account information.
- Pinterest boards, including board IDs, names, descriptions, and privacy settings.
- Information about Pins created or managed through the application.

The application uses this information to select boards, manage publishing, and record publication results.

### Information created within the application

Pinterest Autopilot also stores information generated through its own features, including:

- Pin titles and descriptions.
- Selected Etsy listing and image references.
- Selected Pinterest board information.
- Queue status and scheduled publication times.
- Publication status, Pinterest Pin IDs, and publication timestamps.
- Retry counts, compliance review results, exclusions, and application activity logs.

The application does not intentionally collect personal information about Etsy buyers, Pinterest users, or visitors to third-party websites.

## 3. How Information Is Used

Information accessed by Pinterest Autopilot is used only to operate the application's features, including:

- Synchronizing the owner's Etsy shop listings and images.
- Organizing and reviewing listing images.
- Preparing Pin titles, descriptions, and destination links.
- Managing publishing queues and schedules.
- Publishing approved Pins to the owner's Pinterest account.
- Recording publication results and troubleshooting application errors.
- Applying listing exclusions and content-compliance rules.

We do not sell personal information or use the collected shop information for advertising, profiling, or unrelated commercial purposes.

## 4. Data Storage and Security

Pinterest Autopilot is designed to run locally on the owner's computer.

Application data is stored in a local SQLite database and supporting local files. The application does not use a remote application database or cloud storage service for its shop catalog, image library, publishing queue, or activity history.

OAuth credentials and other sensitive credentials are stored locally. OAuth tokens and client credentials are encrypted at rest using the application's local encryption mechanism. The encryption key is maintained locally on the same computer.

Access to the application is intended to remain restricted to the local machine. The application does not provide public user registration or shared accounts.

Although reasonable technical measures are used to protect locally stored information, no method of electronic storage or transmission can be guaranteed to be completely secure. The security of the computer, its operating system, and its local files also depends on the owner maintaining appropriate device security.

## 5. Information Shared With Third-Party Services

Pinterest Autopilot communicates with third-party services only when needed to provide its features.

### Etsy

The application communicates with the official Etsy API to retrieve authorized shop and listing information.

Etsy processes information according to its own privacy policy and API terms.

### Pinterest

The application communicates with the official Pinterest API to authenticate the owner's account, retrieve account and board information, and create Pins when publishing is enabled.

When a Pin is published, the application sends Pinterest the information required for that Pin, which may include:

- Pin title.
- Pin description.
- Destination URL linking to the Etsy listing.
- Image URL.
- Selected Pinterest board ID.

Pinterest processes this information according to its own privacy policy and applicable developer terms.

### Google Fonts

The application's interface may load fonts from Google Fonts. When the interface requests these fonts, the browser may communicate with Google's font services. These requests are separate from the application's Etsy and Pinterest data processing.

Pinterest Autopilot does not use advertising trackers, analytics services, or third-party error-monitoring services.

## 6. Data Transfers

Although the application's working database and files are stored locally, information is transmitted to Etsy and Pinterest when the corresponding API features are used.

These services may process information on servers located in countries other than the country where the application is operated. Their own privacy policies and terms govern their handling of that information.

## 7. Data Retention and Deletion

Application data is retained locally for as long as it is needed to operate the application and maintain its publishing history.

The owner can:

- Disconnect the Etsy account to remove stored Etsy authentication credentials and associated connection metadata.
- Disconnect the Pinterest account to remove stored Pinterest authentication credentials and associated connection metadata.
- Delete individual queue entries, reference images, and policy documents using the application's available features.
- Remove all locally stored application data by stopping the application and deleting its local data directory.

Deleting the local application data directory removes the local database, encryption key, stored credentials, listing and image data, publishing records, and other files contained in that directory.

Disconnecting an account from Pinterest Autopilot does not necessarily revoke the application's authorization with Etsy or Pinterest. The owner can separately revoke access through the respective platform's account security or connected-app settings.

Deleting local data does not delete Pins already published to Pinterest or listings stored on Etsy. Those must be managed through the respective platforms.

## 8. Account Permissions and Authorization

Etsy and Pinterest access is granted by the account owner through their respective authorization processes.

The application uses only the permissions needed for its stated functionality. Etsy access is read-only for shop and listing information. Pinterest permissions support account and board access and Pin management.

The owner can disconnect either account from the application's settings and can revoke authorization directly through the relevant platform.

## 9. Children's Privacy

Pinterest Autopilot is a private business tool and is not designed for children. It does not knowingly collect personal information from children.

## 10. Changes to This Privacy Policy

This Privacy Policy may be updated when application functionality, data practices, or applicable requirements change.

The latest version will be published at this policy's public URL, with the updated date shown at the top.
